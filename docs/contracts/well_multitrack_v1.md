# well_multitrack_v1 Contract

Canonical backend-owned viewer package contract for the MultiViewer
Well Log Viewer.

**Version:** well_multitrack_v1  
**Status:** Scaffold (WL-BUILD-001)  
**Owner:** Backend — well_viewer_package_service

## Authority rule

The backend owns this contract.  
The frontend must render it through an adapter.  
The Equinor ViDEx internal data shape must NOT become this contract.

## Field notes

- `samples_url`: Backend-owned URL for fetching curve sample data.
  The frontend fetches samples via this URL. It does not parse LAS
  or construct samples independently.

- `qaqc_findings`: Generated by the backend `well_qaqc_service`.
  Frontend displays findings; it does not infer them.

- `tracks`: Populated by `well_viewer_package_service` from MSI-registered
  representations. Empty in WL-BUILD-001 scaffold state.

## Data flow

```
LAS source file
  -> backend well import service
    -> MSI dataset/source/representation registration
      -> backend well_viewer_package_service (generates this contract)
        -> frontend MultiViewer adapter (equinorWellLogAdapter.ts)
          -> @equinor/videx-wellog renderer
```

## What must NOT happen

- Frontend must not construct or duplicate this contract shape.
- ViDEx props must not be returned from the backend API.
- Frontend must not parse LAS to populate tracks or curves.
- Frontend must not infer QAQC findings.
